# Умный дом: ООП-прототип агента

Проект по направлению «Умный дом» в рамках курса «Мультиагентные системы ИИ».

## Что внутри:
- `docs/passport.md` — паспорт проекта (проблема, цель, задачи).
- `data/smart_home_events_raw.csv` — синтетические данные с датчиков.
- `agent_state.py` — код агента (словарь порогов, обработка событий).
- `src/` и `tests/` — заготовки для будущего кода и тестов.

## Запуск
```bash
python agent_state.py
